# نظام مراقبة أسعار Google AI Pro (18 شهر) + تنبيهات Telegram

يراقب MAADS وZ2U وDriffle، ويرسل: تنبيه «أقل من 200 جنيه» مع تذكير كل ساعة (قابل للتعديل) تتبعه رسالة بجدول الأسعار حتى الضغط على رابط التتبع، تقارير تغيّر الأسعار، تقريرًا يوميًا، وأوامر `/start /status /pause /resume /prices /help`.
بايثون 3.11+ بدون أي مكتبات خارجية. قاعدة البيانات SQLite.

## حالة المواقع (تم فحصها فعليًا في 2026-10-26)
| الموقع | الطريقة | الحالة |
|---|---|---|
| MAADS | JSON-LD (`priceCurrency=EGP`) من الصفحة | ✅ يعمل (قراءة فعلية) |
| Z2U | عنصر السعر في HTML (USD، «لا يشمل رسوم الدفع») | ✅ يعمل (قراءة فعلية) |
| Driffle | الصفحة تردّ `403 Blocked` حتى لمتصفح Playwright عادي من IP الاستضافة السحابية | ⛔ **محجوب** |

**Driffle:** النظام لا يتجاوز الحماية. يعرض Driffle كـ «غير متاح / فشل الفحص» ويرسل إشعار خطأ واضحًا بعد 3 محاولات فاشلة، ولا يخمّن سعرًا. قد يعمل من IP الـVPS الخاص بك (الحظر غالبًا حسب الـIP/الدولة) — جرّب `python -m aipro check` على الخادم. أي بديل (API رسمي/شراكة Driffle أو مفتاح API) يُضاف بتعديل `aipro/sites/driffle.py` فقط. محلّل Driffle (JSON-LD بعملة EGP) **غير مُختبر على صفحة حقيقية** لأن الصفحة لم تُفتح؛ سيعرض «تحتاج مراجعة» بدل التخمين إن اختلف الشكل.

## 1) إنشاء بوت Telegram
1. افتح `@BotFather` ← `/newbot` ← اختر الاسم ← انسخ **Bot Token**.
2. أرسل `/start` لبوتك من حسابك.
3. بعد ضبط التوكن في `.env` شغّل `python -m aipro chat-id` ← سيطبع رقم محادثتك ← ضعه في `TELEGRAM_CHAT_ID`.
   (البوت يتجاهل أي محادثة غير هذا الرقم.)
> ⚠️ لا تشارك التوكن في أي محادثة. إن ظهر في مكان عام: `@BotFather` ← `/revoke` لتوليد توكن جديد.

## 2) الإعداد
```bash
cp .env.example .env && chmod 600 .env    # املأ TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID
```
كل الإعدادات في `.env` (مدة الفحص `CHECK_INTERVAL_SECONDS=300`، التذكير `REMINDER_INTERVAL_SECONDS=3600`، الحد `THRESHOLD_EGP=200`، وقت التقرير اليومي `DAILY_REPORT_TIME`…). `.env` مستثنى من Git، والتوكن لا يظهر في السجلات (يُحجب تلقائيًا).

## 3) التشغيل محليًا
```bash
python3 -m aipro test-telegram   # رسالة تجريبية
python3 -m aipro check           # فحص واحد وطباعة النتيجة
python3 -m aipro run             # تشغيل مستمر
pip install -r requirements-dev.txt && pytest   # الاختبارات
```

## 4) النشر على VPS (24/7)
أي VPS صغير (1 vCPU / 512MB) يكفي. **رابط التتبع يحتاج نطاقًا بـHTTPS** (مثلاً `track.example.com` يشير بسجل A إلى IP الخادم). بدون `TRACK_BASE_URL` يُرسل رابط المنتج مباشرة مع زر «🔕 أوقف التذكير» داخل Telegram.

### أ) Docker (الأسهل)
```bash
git clone <مستودعك> /opt/aipro && cd /opt/aipro
cp .env.example .env && nano .env          # TRACK_BASE_URL=https://track.example.com
sed -i 's/track.example.com/نطاقك/' deploy/Caddyfile
docker compose up -d --build              # restart: unless-stopped يعيد التشغيل بعد الأعطال/إعادة الإقلاع
docker compose logs -f aipro
```
### ب) systemd
```bash
sudo useradd -r -m -d /opt/aipro aipro && sudo cp -r . /opt/aipro && sudo chown -R aipro /opt/aipro
sudo cp /opt/aipro/deploy/aipro.service /etc/systemd/system/
sudo systemctl enable --now aipro && journalctl -u aipro -f
# HTTPS: ثبّت Caddy واستخدم deploy/Caddyfile (يمرّر /track/* و /health فقط إلى 127.0.0.1:8080)
```
`Restart=always` يعيد التشغيل بعد أي عطل. نسخة ثانية بالخطأ لا تعمل (قفل ملف على قاعدة البيانات).

## 5) النسخ الاحتياطي
```bash
sudo cp deploy/aipro-backup.* /etc/systemd/system/ && sudo systemctl enable --now aipro-backup.timer
```
نسخة مضغوطة يوميًا 03:30 في `/opt/aipro/backups` (آخر 30 يومًا)، متسقة أثناء التشغيل. الاستعادة: أوقف الخدمة، `gunzip` النسخة وضعها مكان `data/aipro.db`. انسخ المجلد خارج الخادم دوريًا (rclone/scp).

## 6) كيف يعمل (مختصر)
- **فحص مستقل لكل موقع** (خيط لكل موقع)؛ تعطل موقع لا يوقف الباقي. عند الحظر/429 يزيد الفاصل تدريجيًا (حتى ساعة).
- **لا تخمين:** سعر مفقود/غير مقروء/عملة غير متوقعة ⇒ فشل فحص («تحتاج مراجعة») بدون تغيير آخر سعر معروف ولا تنبيه.
- **تغيّر مؤكد:** القيمة الجديدة تُقبل بعد قراءتين متتاليتين (`CONFIRM_CHECKS=2`). أول قراءة = خط أساس بلا تقرير. تغيّر سعر الصرف وحده ليس تغيّر سعر.
- **أقل من 200:** مقارنة صارمة (`< 200`)؛ Z2U يُحوَّل بسعر الصرف أولًا. بدون سعر صرف موثوق (أو أقدم من 48 ساعة) لا يُحكم على Z2U ويُعرض بالدولار فقط.
- **دورة التنبيه:** تبدأ عند النزول تحت 200، تنتهي عند 200 أو أكثر، ودورة جديدة عند النزول مجددًا. الضغط على رابط التتبع (`/track/<id>?c=<cycle>`) يوقف تذكيرات **هذا المنتج في هذه الدورة** فقط ثم يحوّل لصفحة المنتج. الضغط يثبت فتح الرابط فقط لا القراءة ولا الشراء. زحف معاينة الروابط (bots/HEAD) لا يُحسب ضغطة.
- **منع التكرار:** كل رسالة لها مفتاح فريد في جدول `messages` (تنبيه/دورة، تقرير/تغيّر، تذكير/رقمه، يومي/تاريخ) ⇒ إعادة التشغيل أو الفحص المتكرر لا يكرر الرسائل، والرسائل الفاشلة تُعاد حتى تُرسل.
- **/pause** يوقف الفحص والتنبيهات دون حذف بيانات؛ **/resume** يفحص فورًا ولا تُرسل تذكيرات قبل قراءة جديدة ناجحة. التقرير اليومي يصل أثناء الإيقاف مع تنبيه بذلك.
- **سعر الصرف:** `open.er-api.com` (سعر مرجعي يُحدَّث يوميًا؛ قد يختلف عن سعر السوق/البنوك في مصر) ويُعرض مع وقت التحديث. للحصول على مصدر آخر عدّل `aipro/fx.py`.
- Z2U يعرض **السعر الأساسي بدون رسوم الدفع**؛ السعر النهائي يظهر عند الدفع فقط.
- روابط الشراء لا تُنفَّذ تلقائيًا أبدًا.

## 7) التكلفة المتوقعة
- VPS صغير: ~4–6 دولار/شهر (Hetzner/DigitalOcean/Contabo). نطاق: ~10–15 دولار/سنة (اختياري لكنه لازم لرابط التتبع HTTPS؛ بديل مجاني: نطاق فرعي مجاني + Caddy، أو Cloudflare Tunnel).
- Telegram وسعر الصرف وCaddy/Let's Encrypt: مجانية. لا خدمات مدفوعة إلزامية. اختياري: بروكسي/API مدفوع لـDriffle إن لزم، بشرط أن يكون مسموحًا من الموقع.
